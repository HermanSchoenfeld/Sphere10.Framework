# Network

URL parsing and building, query strings, the MIME type table and video-sharing link detection. Nothing here opens a connection.

`Tools.Url` parses, combines and encodes URLs, builds query strings, makes URL slugs and DOM-safe identifiers, and recognizes YouTube, Rumble, Vimeo and BitChute links as a `VideoSharingPlatform`. `QueryStringBuilder` assembles query strings from typed values. `MimeHelper` maps a file extension, with or without its leading dot, to a MIME type and returns `application/octet-stream` for an extension it does not know. Its table of about 1,400 extensions is generated by [`scripts/generate-mime-types.py`](../../../scripts/generate-mime-types.py) from [mime-db](https://github.com/jshttp/mime-db) (MIT), which combines the IANA registry with the Apache and nginx type maps, and is embedded compressed: the file is [`Resources/MimeTypes.tsv.gz`](../Resources/MimeTypes.tsv.gz), which [`Properties/Resources.resx`](../Properties/Resources.resx) embeds as the generated `Resources.MimeTypes`. A `SynchronizedLazyLoad` reads it into memory on the first lookup, so code that never looks up a MIME type pays nothing for it. Regenerate the table rather than editing it: the script documents how it chooses between types that claim the same extension. `Tools.FileSystem.GetMimeType` and `TryGetMimeType` (in [IO](../IO/README.md)) front it and take a file path, a file name or an extension alone, such as `"report.pdf"`, `"png"` or `".png"`. `TryGetMimeType` returns `false` only for a null, empty or blank argument, and `GetMimeType` throws `InvalidOperationException` in that case. `FileInfo.GetMimeType()` in [Extensions](../Extensions/README.md) uses the file's extension.

```csharp
var pdf = Tools.FileSystem.GetMimeType("pdf");                          // "application/pdf"
var png = Tools.FileSystem.GetMimeType(@"C:\Images\logo.png");          // "image/png"
var webp = Tools.FileSystem.GetMimeType("webp");                        // "image/webp"
var unknown = Tools.FileSystem.GetMimeType(".xyz123");                   // "application/octet-stream"
```

DNS, ping, traceroute, WHOIS, TCP port probes, DNS and TLS ClientHello decoding, SMTP mail, downloads, `NetworkProbeDataSource` and `UrlShortner` are in the [Communications network domain](../../Sphere10.Framework.Communications/Network/README.md), so the core library does not depend on the .NET networking assemblies.

`Tools.Url.ToUrlSlug(value, allowUnicode: true)` retains Unicode letters, decimal digits and combining marks in lowercase NFC-normalized slugs, including supplementary-plane letters. It still removes reserved syntax and control characters. The result is a readable path segment, not a percent-encoded request URI. The single-argument overload retains its existing ASCII/diacritic-removal behavior; `ToHtml4DOMObjectID` also retains that character policy. Both slug modes spell the language name `C#` as `c-sharp` before filtering punctuation (for example, `Learn C#` becomes `learn-c-sharp`). Unrelated hashes are still removed.
