# Separator

A two-tone horizontal or vertical separator line control.

`SeparatorLine` draws two adjacent one-pixel lines in `FirstColor` and `SecondColor`, which gives the etched look of a classic dialog separator. `LineStyle` chooses the orientation, and `DashStyle` sets the pen pattern.

## Contents

| Type | Kind | Purpose |
|---|---|---|
| [`LineStyle`](LineStyle.cs) | enum | Horizontal or vertical orientation of a `SeparatorLine` |

### Controls

| Type | Kind | Purpose |
|---|---|---|
| [`SeparatorLine`](Controls/SeparatorLine.cs) | class | Draws two adjacent lines in configurable colours and dash style as a horizontal or vertical separator |
