# Resources

The Android resource files of this legacy Xamarin.Android library and the resource-ID class generated from them.

`Resource.designer.cs` is generated by the Xamarin.Android build tasks and must not be edited by hand. Its static constructor calls `ResourceIdManager.UpdateIdValues()`, and its nested classes, such as `Animation`, hold integer IDs for the library's own resources and for those of the AppCompat support library. `values/Strings.xml` holds the project template's `hello` and `app_name` strings, and `AboutResources.txt` is the template's note on Android resource folders. No solution or CI job builds this project, as the [project README](../README.md) explains.
