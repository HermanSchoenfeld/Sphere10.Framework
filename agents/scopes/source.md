# Source Instructions

These instructions apply to repository-root paths under `src/**`. Before
substantive work, read [the master entry point](../README.md) in full and follow
its required workflow, skill and guideline reading sequence.

Read the affected project READMEs and inspect the consumers of the source being
changed. Use the [Patterns and Practices index](../../docs/guidelines/patterns-and-practices.md)
to select the relevant implementation topics; read each selected file before
choosing or changing the implementation. Follow
[Code Styling](../../docs/guidelines/code-styling.md) for source and C# examples.
